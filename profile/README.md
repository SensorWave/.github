# SensorWave 📊

### C'est quoi SensorWave ?

SensorWave est une plateforme SaaS dédiée à la gestion et l’intégration de capteurs IoT.
Notre mission : simplifier la collecte, le traitement et la visualisation des données de température à grande échelle.
